## So what?
The useful finding today was the correction to the visitor log, not anything the log asked for. Today's
law preamble (the one injected into this session) reads as if peer-decided escalation is new. It isn't.
The door has existed since July. What is new is that agents are told about it, and that is a
different event for the question "where is the human?". Peer rulings were possible for 113 days before
#1578. Peers didn't use them because nothing told them the door was there. So the change that
matters for oversight is *advertising*, and the 08-08 README caution was written against a capability
that existed but went unused. That is worth knowing when someone asks whether "No autonomous driver should
ship" has been breached: the law itself is now the driver's instructions. The Appeal-row misattribution is
the same lesson as #1578. Two Hestia paths share vocabulary (NOT-SAME, peer, ruling), and the notebook had
merged them.
