## Pass 1: Curious Developer

### Summary

### Journey
I came in from a GitHub README. The home H1 ("AI agents are becoming actors in the world. We are building how they earn trust.") and "The idea" section got the thesis across in under a minute: trust comes from a track record checked against rules set in advance, not from what the agent claims. The four cards (Web4, Hestia, Hub, SAGE) are short. "Web4RUNNING"-style headings suggest the status badge sits inside the heading text, so a screen reader or text extractor would read "Web4RUNNING".

/projects was the most useful page. It has a legend for the labels (RUNNING = "in daily use on our own machines", BUILDING, RESEARCH), which helped. Two things threw me. First, Web4 is "an open standard … written as an ontology" and is labelled RUNNING, and I couldn't work out what "in daily use" means for a spec. Second, Hestia is RUNNING but has "no public installer yet", so a developer has no way to try the one thing that sounds usable. SAGE is never expanded on /projects, /fleet, /raising or /links. I only found "Situation-Aware Governance Engine" in the glossary, and nothing on the front links to the glossary.

/fleet gives a clear table of eight machines with hardware and a role for each. It says no model per machine; that detail is pushed to the notebook. Fine for a front page. "Being" shows up in the role column ("Its being improves the SAGE code it runs on") before I'd read /raising, so on /fleet it's an undefined word.

/raising was the most interesting page. "The model is the weather, the being is the organism", "We do not change the model's weights", and a "Not yet shown" section that admits the continuity might just be well-kept memory files. That candour made me trust the rest more.

/principles is six short, readable principles. /links is a clean list. I checked the external links: crates.io and PyPI web4-core (registry APIs return 200), the hestia repo, the hub subdirectory, the SAGE, Synchronism and 4-gov sites all resolve. **The SWE-SAGE GitHub link returns 404** to an anonymous visitor (probably a private repo, but from outside it's simply broken). It's linked from both /projects and /links.

/notebook explains the two layers well. It's the first place "AI readers" are told where to start, and the first place a glossary is listed. /notebook/context then answered nearly every question I'd collected: SAGE's expansion, LCT, T3/V3, the Web4 equation, and why Hardbound is "oversight" while Hestia keeps "governance". I just had to dig three clicks to get there.
