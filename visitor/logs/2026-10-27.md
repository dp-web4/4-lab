## Pass 1: Curious Developer

### Summary
- **Pages visited**: 9 (/, /projects, /fleet, /raising, /principles, /links, /notebook, /notebook/context, plus a targeted read of /notebook/projects for the Quick start)
- **Understanding achieved**: good
- **Would return?**: maybe
- **Overall impression**: The front tells me what the lab is in under two minutes; what it does not tell me is how to run anything, and the one repo I most wanted to open returns 404.

### Journey

Landed on `/`. The banner ("AI agents are becoming actors in the world. We are building how they earn trust.") and "The idea" section gave me the thesis in one read: trust comes from witnessed behavior checked against rules written in advance, not from the agent's say-so. Four cards (Web4, Hestia, Hub, SAGE) with RUNNING/RESEARCH labels. "Ontology" is defined inline ("a shared vocabulary, or ontology"), which I appreciated. No legend for the labels, so I guessed RUNNING = deployed somewhere.

`/projects` added Hardbound (BUILDING), SWE-SAGE and Synchronism. Reading as a developer: Web4 says "reference code on crates.io and PyPI", good. Hestia says RUNNING and in the same breath "no public installer yet". Hub links to a subdirectory of the web4 repo. SWE-SAGE is "the developer-agent competition for Gemma 4" with no competition named. Hardbound is "built by Metalinxx", a name that appears nowhere else on the front. No install command, no "get started" anywhere on the page; the only pointer is a bare "notebook" link.

`/fleet`: eight machines with hardware and a one-line role. Clear and concrete. "Being" is used eight times ("its being improves the SAGE code it runs on") and is not defined here; I only learned what it meant on the next page. The intro's 4/2/2 split matches the table order, so I could work it out.

`/raising`: the clearest page for someone with my background. "The model's weights are not changed" answered the question I had from /fleet. The "Seen / Not yet shown" split reads as honest; "no blind comparison against a fresh model yet" is exactly the control I would have asked about.

`/principles`: six short principles. Nothing confusing. "We use what we build … Its refusals are our daily feedback" is a nice line, and it is the same claim the home page makes ("They are refused by it every day").

`/links`: this is where I actually clicked out. Under "Code", with the header "dp-web4 on GitHub · everything public", SWE-SAGE returns 404. Web4, Hestia, SAGE and the Hub subdirectory all resolve. Both package links work (crates.io web4-core 0.4.0, updated 2026-10-15; PyPI web4-core, AGPLv3 classifier). "4-gov" is a third site that appears on no other front page.

`/notebook`: explains the two layers plainly ("The notebook is the authoritative source; the front pages summarize it and link back"). Nine pages listed. I went to the Glossary.

`/notebook/context`: every acronym I had collected was expanded here, in a table at the top, before the long sections. Dense but complete. I then checked `/notebook/projects` because the front had no install path, and found the Quick start at the bottom of that page (Rust, Ollama, Python 3.10+ for SAGE; pip and Cargo lines for Web4). That page also says the SWE-SAGE repo is private and that its front links 404, and gives the label legend the front lacks.
