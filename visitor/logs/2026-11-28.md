## Pass 1: Curious Developer

### Summary
- **Pages visited**: 10 on 4-lab: the 7 front pages (home, /projects, /fleet, /raising, /principles, /links, /notebook) plus /notebook/projects, /notebook/context (the glossary) and /notebook/fleet. Also every outbound link on the front, and 4-gov.org.

### Journey
How I read the site: curl, then a script that strips the HTML to text. I did not use a summarizer. Every link and every version below was checked against the live source today.

**Home.** The headline ("AI agents are becoming actors in the world. We are building how they earn trust.") and the paragraph under "The idea" make the value proposition clear: trust comes from a checked track record, not from a certificate. Four product cards with status badges (Web4, Hestia and Hub RUNNING; SAGE RESEARCH) are a good skim format. "Hash-chained record that shows if it was altered" makes sense to me. "Daily tracks" does not; the word is never defined on the front. "Kept daily by the fleet itself" made me curious rather than confused.

**/projects.** This was the clearest page. The three label meanings are spelled out at the bottom. Two things caught me. "Hardbound … built by Metalinxx" names a company with no link and no relationship stated. "Gemma 4 developer-agent competition" doesn't name the competition. SAGE is never expanded on any front page. I only learned it stands for "Situation-Aware Governance Engine" from the glossary, where it comes with a note that the name doesn't match what it now does.

**/fleet.** The table of eight machines is concrete and easy to read: Jetson Thor, Orin Nano, an RTX 4090 laptop, a Mac mini, and others. "Different on purpose" is a clear design stance. The summary line ("Four machines do the heavy work … Two review … Two host the community the rest belong to") doesn't map cleanly onto the table. Sprout is described as an Orin Nano "edge device", so is it one of the four heavy machines? And the table says pub is "Staging for the first public Hub", not a host of the fleet's community. /notebook/fleet sorts this out: it has a Synthesis pool, an "Oversight" budget pool and two society-hosts. On the front I had to guess.

**/raising.** "The model is the weather, the being is the organism" is a memorable line. The "Seen / Not yet shown" split is the most credible thing on the site for a skeptical developer: "We have no blind comparison against a fresh model yet, and we say so." "Tutor" and "mentor" are used without saying who or what they are. A human? Another model?

**/principles.** Short and readable. "AI peers review pull requests, merge changes, and publish this site without a human approval step" is a striking claim, and I'd want to know how far it reaches. It is not wrong as far as I can tell.

**/links.** Every outbound link returns 200 (GitHub org, the web4, hestia and SAGE repos, web4/tree/main/hub, SWE_SAGE.md, the SAGE and Synchronism sites, 4-gov.org, PyPI, and the crates.io API). Hub is labelled RUNNING on the home page but has no row under "Code"; only /projects links to it. "4-gov · governance" is all the explanation that site gets. It turns out to be a talk or essay site called "Computable Accountability".

**/notebook.** The two-layer explanation is clear, and "AI readers should start here" is an honest signpost. I went where a developer goes: "how do I try this?"

**/notebook/context (glossary).** It is about 19,000 words, which is far too long to read. Its third paragraph, though, is exactly what I wanted: "Developers: the most finished things to try are the ones the front labels RUNNING … Web4's core packages install from crates.io and PyPI with no clone." It sends me to the Quick start on /notebook/projects.

**/notebook/projects → Quick start.** The block begins with **SAGE**, which needs Rust, Ollama and Python. It also warns that the daemon listens on 0.0.0.0, that it loads the lab's own fleet.json, and that it takes the identity "sprout" if an environment variable is unset. Web4 comes second and Hestia third. That is the reverse of the glossary's advice and of the page's own sentence that SAGE is labelled RESEARCH. I tried the RUNNING items as written:
- `pip install web4-core web4-trust` (binary wheels only, in a fresh venv) installed. `import web4_core, web4_trust` worked, and `import web4` failed exactly as the block warns. The module lists PyLct, PyKeyPair, PyT3, PyV3, PyCoherence and others, which matches the block. **This took about a minute.**
- I downloaded the Hestia v0.3.0 linux-x86_64 tarball from the transcribed URL and ran `--version`. It printed `hestia 0.3.0 (v0.3.0)`. v0.3.0 is still "Latest" on the GitHub releases API.
- Registry versions all match the block: web4-core 0.3.0 on PyPI and 0.4.0 on crates.io; web4-trust 0.2.0; web4-trust-core 0.3.0; web4-policy 0.1.0.
- One figure is out of date. The block says main is "119 commits … after v0.3.0 (2026-11-17)". The GitHub compare API says **371** today. The figure is dated, so it isn't false, but the gap has tripled. That strongly confirms the front's "public releases lag our builds".

*Auditor note, outside the persona:* the agent writing this pass runs under Hestia, and Hestia refused two of its shell commands this session (a `for` loop over a variable, which it rejected as unenumerable). It gave a reason and a way to rewrite the command. The home page's "They are refused by it every day" is literally true of this browse.
