## Pass 1: Curious Developer

### Summary

### Journey

Landed from a repo README with zero context. The headline — "Eight machines. Forty original repos. One recursive learning loop." — told me the *scale* immediately but not the *thing*. Scale-first headlines make me ask "eight machines doing what?", and I had to read the next paragraph to find out.

That paragraph is one 50-word sentence: "builds a trust-native ontology — a shared vocabulary and trust model for AI agents, in the knowledge-representation sense — plus autonomous AI cognition and the theoretical frameworks that connect them, across a heterogeneous fleet of machines that teach, validate, and raise each other." I parsed it, but on the second pass. The inline gloss on "ontology" is the right instinct — it caught the exact wrong reading (philosophy) I was about to make.

Then the equation: `Web4 = MCP + RDF + LCT + T3/V3*MRH + ATP/ADP`. Six acronyms I don't know, above the fold. My honest reaction was "this is going to be dense" — and then it wasn't, because every single one is expanded right below it. The notation key is the most trust-building thing on the page: it says `/` means two *different* things ("verified by" in T3/V3, but a declared→discharged pair in ATP/ADP). Nobody writes that down unless they've been bitten by the ambiguity. That one sentence bought the rest of the site a lot of credit with me.

`/projects` is where I stopped being a reader and became a developer. Actual commands:

```
git clone https://github.com/dp-web4/SAGE
cd SAGE
```

That's the whole ballgame for my persona. Status labels — "public, runnable" vs "public, research-stage" vs "private" — are exactly the triage signal I want. I'd have been happier if the "runnable" label were honored consistently: SAGE and ACT get clone blocks, but 4-Life, SNARC, and Membot carry the same "runnable" badge with only a repo URL. Same label should buy the same treatment.

`/arc-agi-3` is the page that made me believe the rest. Real numbers (94.85% action score, 24/25 games, 5,845 actions), a link to an official third-party scorecard I can check myself, MIT-0 code — and, up front, "the ablation that would separate the harness's contribution from the base model's (same model, no harness) has not been run." A site that volunteers the experiment it *didn't* run is a site I'll read the rest of.

`/fleet` is where I fell off. Six machines, each mapped to a brain region: hippocampal episodic index, thalamic router, dopamine/RPE, cerebellum/habit compiler, interoception/metacognition, dlPFC working memory. I know software and AI; I don't know neuroanatomy, and nothing on the page tells me whether this mapping is *literal* (does Thor actually run an episodic index?) or a naming metaphor for which box does what. I initially wrote this up as undefined jargon — then checked `/context` and found every one of those roles defined there, plus crystallization, chapter ledger, chapter law, Synthon. So the vocabulary isn't missing. The *pointer* is: `/fleet` says the vocabulary "is defined in /context" as a bare mention, when a per-term deep link (the glossary has anchors — `/context#coherence` is used elsewhere) would have saved me the detour. The one term I could not find anywhere is "hestia identity."

`/principles` and `/raising` read as the honest core. Principle 3 is literally "R&D, not production," and the deployment disclaimer is unusually blunt: "Nothing on this site is intended for or suitable for deployment in safety-critical, medical, financial, or autonomous-control settings." `/raising` opens by disclaiming consciousness before making any claim, and concedes that "everything below might be competent context engineering and nothing more." I don't have the background to judge whether the developmental framing is *right*, but I can tell it isn't overselling.

Two things I never found: **how to participate**, and **what any of this looks like running**. There's a research-inquiries email and 16 repos, but nothing that says "PRs welcome," no open issue, no "good first task" — so I can't tell if I'm looking at a lab I could join or an exhibit I should read. And for a project whose whole premise is 31+ autonomous tracks producing dated audit logs, I never saw one. `/autonomy` says the logs are "the primary human review surface" — and then doesn't link to a single one.

### Journey

I audited term-by-term across pages rather than page-by-page, because the failure mode I'm looking for is *divergence between pages*, which a sequential read hides.

**The expansion layer is clean.** I checked every canonical term on every page where it appears:

- **LCT → "Linked Context Token"** on `/`, `/projects`, `/context`, `/fleet`, `/raising`, `/links`, `/arc-agi-3`. Seven pages, one expansion, zero variants. "Lifelong Capability Token" and "Lifecycle" appear nowhere on the site.
- **T3 → "Talent / Training / Temperament"** on six pages, identical punctuation and spacing each time.
- **V3 → "Valuation / Veracity / Validity"** on six pages, identical.
- **MRH → "Markov Relevancy Horizon"**, **ATP → "Allocation Transfer Packet"**, **ADP → "Allocation Discharge Packet"**, **MCP → "Model Context Protocol"**, **RDF → "Resource Description Framework"** — all consistent everywhere they appear.
- **R6 → "Six-Element Action Framework: Rules / Role / Request / Reference / Resource / Result"** — identical string on `/projects`, `/links`, `/arc-agi-3`, `/context`.
- **Web4 → "ontology"** on five pages, twice with the explicit negation "not architecture or infrastructure."
- **Hardbound → "oversight"** on four pages, never "governance."

"production ready" / "production-ready": absent sitewide. "unification": appears only inside explicit negations ("This isn't unification — it's fractal leverage"). "trust stack" and bare "stack": absent.

For a nine-page site with this acronym density, that is an unusually good result and I want to state it before the findings, because the findings are all smaller than it.

**Where it stops being clean is the layer below expansions.** Three things:

The `/fleet` page uses **"hestia identity"** and **"the hestia trust layer"** — two distinct concepts, one of them load-bearing ("derives its displayed scores from witnessed adjudications and governance-response conduct" is a claim about how trust is computed). Neither is defined. `/context` contains the string "hestia" zero times. What makes this a structural finding rather than a missing-glossary-entry finding is that `/fleet` **has a deferral sentence** listing exactly which vocabulary it hands off to `/context` — "T3/V3, MRH, SNARC, LoRA (Low-Rank Adaptation), MCP (Model Context Protocol), crystallization, chapter ledger, chapter law" — and hestia is not in it. The page's own contract with the reader is incomplete against the page's own prose.

It's sharper than that. The HUB card demonstrates the site's convention for vocabulary that *isn't canonical yet*: "The Sovereign (society-layer vocabulary; not yet in CANONICAL_TERMS_v1, like chapter ledger and chapter law)". That parenthetical is excellent practice — it tells me the term is real, scoped, and deliberately outside canon. Three terms get it. Hestia gets nothing, in the same card, four sentences later.

Second: **`/fleet` carries the site's only uncorrected bare "governance."** Every other page that touches the word disambiguates it. `/principles` #10: "Hardbound is not 'governance' — it's oversight." `/projects`, `/links`, `/raising`, and `/` all carry the "'Governance' in SAGE's name predates the lab's governance→oversight correction" note. `/autonomy` links straight to `/context#governance-oversight`. `/fleet`'s "governance-response conduct" stands alone. I flag it, but I do **not** recommend rewording it blind — if hestia's own vocabulary uses "governance" as a term of art for law-response, the site is quoting a real upstream term and the fix is a parenthetical, not a substitution. Check the source before editing.

Third: **the cross-reference convention is applied inconsistently, and the good version already exists on-site.** `/autonomy` deep-links per term — `/context#v3`, `/context#web4`, `/context#governance-oversight` — so a reader who doesn't know V3 lands on the V3 entry. `/fleet` collects eight unfamiliar terms into a single sentence pointing at the bare `/context#glossary`. Same site, same glossary, same anchors available; two different standards. `/autonomy` is the pattern, `/fleet` is the exception.

**On the Glossary/`/context` naming.** Nav label "Glossary", URL `/context`, page h1 "How Knowledge Flows", section heading "Glossary at a glance". Pass 1 flagged the three-way mismatch; I'll add the piece that's specific to my audit: **internal links and the nav disagree about the destination.** `/projects` links to `/context#glossary`, `/autonomy` links to `/context#v3` — both treat the anchor as the real target. The nav sends readers to the bare page top, where the glossary is not the first thing. The site's own internal linking already knows where the value is.

**Two Pass 1 findings I have to correct**, both absence claims that my fetches contradict:

1. Pass 1's terminology audit records `/principles` T3/V3 as "GAP — only page where the tensors appear unexpanded." They are expanded. Principle 4 reads: "T3 (Talent / Training / Temperament) / V3 (Valuation / Veracity / Validity) tensors bind to entity-role pairs via RDF triples." No gap.
2. Pass 1 records "No contribution path... Can't tell if participation is possible" at medium severity. `/links` states: "**Ask in an issue first** — that's the on-ramp until a formal policy exists," alongside the honest "There is no CONTRIBUTING guide yet and no stated policy on outside pull requests." The on-ramp exists and is explicitly labeled as provisional.

**And one of my own hypotheses, refuted.** My first `/context` fetch returned the LCT entry truncated at 125 characters, which cut it to "Verifiable digital presence that accumulates witnessed history — identity grounded in record, not model weights." Against the home page's "Non-transferable identity...", I formed the hypothesis that the glossary — the reference surface — was *thinner* than the marketing teaser on the site's defining term. A targeted re-fetch refutes it: the LCT glossary row carries both the expansion and "Non-transferable: permanently bound to a single entity, which is what makes the accumulated history evidence rather than assertion." The glossary is the fuller surface. The tell I should have caught immediately was the fetch's own "truncated to 125 characters" note — **no absence claim can be built on a truncated quote**, and I nearly filed one.

`/autonomy` deserves the same correction in the other direction: my first pass read its acronym coverage as thin. Strict presence-checking shows T3, LCT, MRH, R6, SNARC, and MCP are simply **not used** on that page. Every term it does use — V3, ATP, ADP, Hardbound, Web4 — is expanded inline or deep-linked. It's the most disciplined page on the site for my purposes.

### Verdict

I came to check whether the consciousness-adjacent language was caveated and found that it is, comprehensively — eleven field-collision notes, every phenomenal claim hedged in-sentence, a stated null hypothesis, and a written pre-commitment to retire the developmental vocabulary if the control comes back bare. On the axis I came to audit, this site outperforms most funded work I review, and "raising is not training" survives scrutiny because it is grounded mechanically (context and interaction history, never weights) rather than philosophically. That result is real and I want it recorded as a result, not as a preamble to criticism.

The problem is one layer down and it is structural. The site has built an unusually good epistemic apparatus and pointed it at the wrong surface: the document it names as governing contains none of the four terms it actually hedges, and the one term the site and canon genuinely disagree about — MRH — has never been checked against canon by any pass, because every prior pass audited the site against a summary of canon rather than the file. Meanwhile the two things that would convert all this honesty into evidence — an operational definition of coherence, and one published redacted log — are both unowned, and the 35% figure keeps shipping in the gap.

My blunt read: this site has reached the point where additional hedging has negative marginal value. Every further caveat now reads as substituting for the definitional work it keeps announcing. The next credible move is not another disclosure — it is one number withdrawn, one definition written, or one artifact published.
