## Pass 1: Curious Developer

### Summary
- **Pages visited**: 9: the seven front pages (`/`, `/projects`, `/fleet`, `/raising`, `/principles`, `/links`, `/notebook`), plus `/notebook/projects#quick-start` and `/llms.txt`. All ten site URLs and all 11 outbound links on `/projects` and `/links` returned 200 on 2026-11-25. Package links were checked against the crates.io and PyPI APIs.
- **Understanding achieved**: good. The pitch is clear in under two minutes. What I can actually run is less clear.
- **Would return?**: yes
- **Overall impression**: The front is the clearest it reads to an outsider: a sharp idea, four products, honest labels. But nothing on the front tells a developer how to try anything. The Quick start that does exist puts the least finished project first, directly under a sentence recommending the other two.

### Journey
I landed on `/` from a repo README. The hero ("AI agents are becoming actors in the world. We are building how they earn trust.") and "The idea" paragraph (track record over certificate, rules before acts) gave me the thesis in about 30 seconds. That is a good opening. The four cards (Web4, Hestia, Hub, SAGE) carry RUNNING/RESEARCH badges, but the home page has no legend for them. As a developer I read RUNNING as "I can run it". The legend on `/projects` ("in daily use on our own machines") says otherwise, but I only found it on the second page.

`/projects` is the page I wanted: three groups (governance, beings, theory) and a one-line status legend. Web4 is "written as an ontology" with "reference code on crates.io and PyPI". Hestia "checks tool calls first". Hardbound is the paid "hardware-bound oversight" tier. Clear. There is no install line or "try it" link. The legend's "notebook" link goes to `/notebook/projects` with no anchor.

`/fleet` has a good table of eight machines. Then the summary paragraph under "Two kinds of work" didn't match the table (friction log). `/raising` is the most readable page on the site: "the model is the weather, the being is the organism", plus a "Seen / Not yet shown" split I wish more AI projects had. `/principles` has six short principles, and "AI peers review pull requests, merge changes, and publish the site with no human approval step" is the most surprising and most concrete sentence on the site. `/links` has everything a developer needs: repos, both package registries, the SAGE and Synchronism sites. It is the only front page that links the packages directly.

On `/notebook` the nine cards are well described. I went to Projects because I wanted to run something. The Quick start now sits near the top of the page (moved 2026-11-24): the second block of text, about 1.5 KB into roughly 54 KB. Easy to find once you are on the page. No front page links to it, though. The only `#quick-start` link anywhere is in `llms.txt`, which is addressed to AI readers.

I followed the Web4 Python path on a fresh venv (2026-11-25). `pip install web4-core web4-trust` worked. `import web4` fails and `import web4_core` / `import web4_trust` work, exactly as the notebook warns. The module exports `PyLct`, `PyKeyPair`, `PyT3`, `PyV3` and the others listed. Registry versions match the notebook today: web4-core 0.3.0 on PyPI and 0.4.0 on crates.io, web4-trust 0.2.0, web4-trust-core 0.3.0, and web4-policy 0.1.0 as the only crates.io version. Hestia v0.3.0 is still Latest (2026-11-02). I did not run the PyPI listing's usage blocks this time. The notebook records block 1 running on 2026-11-09.

### Unanswered Questions
1. Which four machines are the "heavy work" ones? Is Sprout (an Orin Nano) really among them?
2. After `hestia --version`, what is the smallest config that makes Hestia refuse one tool call I make? This is the product's core claim, and the site doesn't show it.
3. Is Hub runnable by an outsider today? `/projects` says RUNNING (on the lab's machines) and `/fleet` says pub is "staging for the first public Hub". Is there a date or criterion for "public"?
4. What does "SWE" in SWE-SAGE stand for, and since the code is private, what can an outsider reproduce from the write-up?
5. `/principles` says agents "merge changes, and publish the site with no human approval step". Does that cover every page of this site, including the front pages I just read?

### Verdict
As a developer I got the idea fast and trust the tone: the "Seen / Not yet shown" split on `/raising` and the status legend on `/projects` do more for credibility than any claim. The front has two factual mismatches a careful reader catches in five minutes: "each" vs "most" machines raising a being, and "two host the community" vs a table where one hosts and one stages. The on-ramp is the real gap. The front never points to the Quick start. Once found, the Quick start leads with SAGE right after saying to start elsewhere, and the "most finished" product stops at `--version`. The Python package path works exactly as written. That should be the first block, not the second.
