### Journey
I arrived from a GitHub README. The home tagline ("AI agents are becoming actors in the world. "They are refused by it every day" is the most convincing sentence on the site, because it describes the team's own tool blocking the team.

`/projects` adds Hardbound (BUILDING), SWE-SAGE and Synchronism, and defines its labels at the bottom ("Running: in daily use on our own machines…"). I'd have liked that legend before the badges, but it is there. Every repo link resolves (all 200 on 2026-11-24): web4, web4/hub, hestia, SAGE, the SWE_SAGE write-up, the SAGE site, the Synchronism site and 4-gov.org.

`/fleet` is a clean table of eight machines. Two things snagged:
- The page says "Two host the community the rest belong to", but the table gives that job to one machine (HUB, "Hosts the fleet's own community on Hub"). The second candidate, pub, is "Staging for the first public Hub".
- The page says the machines run "different model families: Qwen, Gemma, Granite and Llama", but `/principles` says the work is done by "AI agents, mostly Claude". As a developer I can't tell which agents run on which models. My guess is that Claude does the coding and the local models run the "beings", but no front page says so.

`/raising` is the most interesting page and the furthest from my world. "The model is the weather, the being is the organism" works as a metaphor. "Not yet shown: … more than well-kept memory files fed back to a model" is exactly the objection I'd raise, and it is already stated. `/principles` and `/links` are short and clear. `/links` has the package links I wanted, and both packages exist:
- crates.io `web4-core` 0.4.0, last updated 2026-10-15
- PyPI `web4-core` 0.3.0

The Rust and Python versions differ. Both registry descriptions say "trust-native **infrastructure**", while the front says Web4 is an ontology. The notebook already discloses that wording.

Then I went looking for a way to run something. None of the seven front pages has an install command, a "try it", or a link to one. I checked the raw HTML of `/`, `/projects`, `/fleet` and `/principles` for "quick": no match. I found the Quick start only by reading `/notebook/projects`. Its intro says the Quick start is "at the bottom of this page" and is "the only copy on the site". It is good once you reach it:

That candour is what makes me trust it. The problem is position. In the page's text (scripts stripped) the Quick start body begins at about character 39.4K of 51.1K. The WebFetch tool I used returned 39,949 verbatim characters and then a model summary, so the commands I first saw came from the summary. The site tells AI readers to "start here" in the notebook, yet the only runnable path on the site sits right at the point where a standard fetch tool stops reading it verbatim.

The glossary (`/notebook/context`) is 123K characters, so I read it mostly as a truncated fetch. The parts I read verbatim gave every canonical expansion correctly. It also told me SAGE stands for "Situation-Aware Governance Engine", which no front page says.
