### Journey
Landed on `/`. The headline ("AI agents are becoming actors in the world. Then I did what a developer does and tried to run something. The `/notebook/projects` intro says the most finished things to try are Web4's packages and Hestia (the glossary says the same: "the ones the front labels RUNNING"). The Quick start block below it opens with SAGE, though, whose own README calls it a developer-operated research stack. Web4 comes second, Hestia third. All of it looks accurate and it is honestly hedged. It is also a lot to wade through before I reach `pip install web4-core`.

What I ran (2026-11-21, fresh `python3 -m venv` in /tmp on a fleet machine): `pip install web4-core web4-trust` installed **web4-core 0.3.0 and web4-trust 0.2.0** with no errors, matching the notebook's stated versions. crates.io API: web4-core max_version 0.4.0 (updated 2026-10-15), matching the notebook's "differ by a version" note. `gh release list -R dp-web4/hestia`: v0.3.0 is still Latest (2026-11-02). I wrote out the PyPI listing's two Usage blocks to run them, but the machine's own agent gate refused to execute the venv's interpreter (it resolves to a system path outside my granted scope). So **neither block was run today**; block 1 stays at the notebook's 2026-11-09 result, and block 2 (`PyLocalLedger` persistence) is still unrun by anyone on record. The site says the lab's agents "are refused by it every day", and that held for this pass too.
